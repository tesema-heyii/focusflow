
# FocusFlow

A responsive productivity and task-management application built
incrementally with native web technologies.

## Current status

The current version provides a static dashboard interface.
Task creation, task persistence, and dynamic task management
have not been implemented yet.

## Technology

- HTML5 for semantic document structure
- CSS3 for styling and responsive layout
- Native browser capabilities

## Project structure

```text
focusflow/
├── index.html
├── css/

│   └── layout.css
├── js/
│   └── main.js
├── tests/

├── .gitignore
└── README.md
```

## Run the current version

1. Open `index.html` in a modern web browser.
2. Resize the browser to test the responsive layout.
3. Use keyboard navigation to check focus indicators.
4. Inspect the page with browser Developer Tools.

## Current features

- Semantic page structure
- Responsive dashboard layout
- Accessible form labels
- Native browser form validation
- Task-entry interface
- Empty-state presentation
- Keyboard focus styling

## Planned features

- Task creation, editing, completion, and deletion
- Search, filtering, sorting, and grouping
- Task statistics and progress
- Browser-based persistence
- JSON import and export
- Automated tests
